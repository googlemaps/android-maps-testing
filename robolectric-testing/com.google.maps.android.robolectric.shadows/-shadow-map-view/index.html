ShadowMapView

@Implements(value = MapView::class)
open class ShadowMapView : ShadowViewGroup

Robolectric shadow for MapView.

Handles lifecycle events, immediately or asynchronously dispatches map callbacks via getMapAsync, and implements 2D canvas drawing operations using Mercator projection to support snapshot and pixel-level testing without an emulator.
