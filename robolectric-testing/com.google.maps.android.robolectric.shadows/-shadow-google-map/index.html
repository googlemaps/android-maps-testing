ShadowGoogleMap

@Implements(value = GoogleMap::class)
open class ShadowGoogleMap

Robolectric shadow for GoogleMap.

Acts as the central in-memory state engine for Google Maps unit tests. Manages map overlays (markers, polygons, polylines, circles, ground overlays, tile overlays), camera tracking, viewport projection calculations, user interaction dispatchers, and snapshot generation.
