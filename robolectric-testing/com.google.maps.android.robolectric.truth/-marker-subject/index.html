MarkerSubject

class MarkerSubject : Subject

Google Truth Subject for fluent, chainable assertions on a Marker.

Designed for "lazy programmer" ergonomics: every assertion method returns this (MarkerSubject) so callers can chain multiple checks or use .apply { ... } blocks without repeating assertThat(marker).
