MapsRobolectricTestRunner

open class MapsRobolectricTestRunner(testClass: Class<*>) : RobolectricTestRunner

Robolectric test runner that registers every Google Maps SDK shadow for the tests it runs.

Other @Config values on the test class or method (such as sdk) still apply, and shadows listed there are added to the Maps shadows.

@RunWith(MapsRobolectricTestRunner::class)
@Config(sdk = [34])
class MyMapTest {
    // All Maps shadows are registered
}
