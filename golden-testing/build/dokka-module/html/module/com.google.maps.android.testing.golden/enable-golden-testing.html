golden-testing/com.google.maps.android.testing.golden/enableGoldenTesting

enableGoldenTesting

fun GoogleMap.enableGoldenTesting(strategy: GoldenTileStrategy = GoldenTileStrategy.CoordinateGrid(), tileSize: Int = 256, fadeIn: Boolean = false, zIndex: Float = -1000f): TileOverlay

Enables deterministic golden screenshot testing on this GoogleMap instance.

Sets GoogleMap.getMapType to GoogleMap.MAP_TYPE_NONE to prevent remote Google tile fetching, and attaches a TileOverlay powered by GoldenTileProvider rendering deterministic synthetic tiles.

Return

The attached TileOverlay.

Parameters

strategy

The tile rasterization strategy to use. Defaults to GoldenTileStrategy.CoordinateGrid.

tileSize

Tile width and height in pixels. Defaults to 256.

fadeIn

Whether tiles should fade in upon loading. Defaults to false for instant, deterministic snapshots.

zIndex

Z-index of the synthetic tile layer. Defaults to -1000f so user overlays (polylines, polygons, markers) render on top.
